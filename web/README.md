# Portfolio source

React + TypeScript + Tailwind + shadcn/ui. The published site is the single file `../docs/index.html`,
served by GitHub Pages; images live in `../docs/assets/img`.

```bash
pnpm install
pnpm dev        # local preview
./build.sh      # type-check, bundle, and write ../docs/index.html
```

Content (write-ups, projects, timeline, certificates) is in `src/data.ts`.
