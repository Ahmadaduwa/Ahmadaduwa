Hard 2026-10-01 · Windows

Attacking Common Services

  1. reconNmap หา service ที่เปิดอยู่สำรวจว่าเครื่องนี้เปิดประตูไว้กี่บาน
  2. enumerateSMB share + credential sprayingเจอโฟลเดอร์แชร์ที่ไม่ล็อก แล้วลองรหัสที่ได้กับทุกบัญชี
  3. escalateMSSQL linked server → sysadminฐานข้อมูลตัวหนึ่งเชื่อมกับอีกตัวที่ให้สิทธิ์ผู้ดูแล จึงยืมสิทธิ์นั้นมาใช้
  4. executexp_cmdshell → NT AUTHORITY\SYSTEMใช้ฐานข้อมูลสั่งงานเครื่องโดยตรง จนได้สิทธิ์สูงสุดของ Windows

จากโฟลเดอร์แชร์ที่ใครก็เปิดได้ ไปจบที่สิทธิ์สูงสุดของเครื่อง เพราะรหัสผ่านถูกใช้ซ้ำและฐานข้อมูลให้สิทธิ์เกินจำเป็น

  • Nmap

Medium 2026-09-27 · Linux

Attacking Common Services

  1. reconNmap ครบทุกพอร์ตสำรวจทุกประตู ไม่ใช่แค่ประตูที่คนใช้บ่อย
  2. enumerateไล่ดู service ทีละตัวดูทีละบริการว่าเปิดให้ทำอะไรได้บ้าง
  3. exploitbrute force ด้วย password list ที่เจอในระบบเจอรายการรหัสผ่านในระบบ แล้วไล่ลองจนเข้าได้
  4. lootเข้า FTP อ่าน flagเข้าไปหยิบไฟล์เป้าหมายออกมา

ผู้ใช้คนเดียวใช้รหัสเดียวกับ 3 service หลุดที่เดียวจึงหลุดทั้งหมด — และถ้าสแกนแค่ 1,000 พอร์ตแรกจะมองไม่เห็น service ที่ซ่อนอยู่เลย

  • Nmap
  • FTP
  • POP3
  • Brute force

Easy 2026-09-26 · ภาษาไทย

Attacking Common Services

  1. reconNmapสำรวจว่าเครื่องเปิดบริการอะไรบ้าง
  2. enumerateหารายชื่อ userหาว่ามีบัญชีผู้ใช้ชื่ออะไร
  3. exploitbrute force รหัสผ่าน → FTPเดารหัสผ่านจนเข้าบริการรับส่งไฟล์ได้
  4. pivotMariaDB เขียน web shellใช้ฐานข้อมูลวางไฟล์คำสั่งไว้ในเว็บ แล้วสั่งงานผ่านหน้าเว็บ

ฐานข้อมูลที่เขียนไฟล์ลงโฟลเดอร์ของเว็บได้ เท่ากับสั่งรันคำสั่งบนเครื่องได้ — รหัสผ่านอ่อนตัวเดียวจึงกลายเป็นการยึดเว็บทั้งตัว

  • Nmap
  • FTP
  • MariaDB
  • Web shell
